# Journal des versions DOROX

## 1.0.0 — 26 juillet 2026

Première version officielle de la Progressive Web App.

- architecture modulaire ;
- base locale IndexedDB avec repli localStorage ;
- migration automatique de l’ancien prototype lorsque ses données sont encore présentes ;
- inventaire de 61 produits ;
- budget habituel et budget exceptionnel du mois ;
- réserve de phase 4 réglable ;
- moteur d’arbitrage conforme aux règles validées ;
- liste proposée avec validation, modification, report et exclusion ;
- mode Courses avec prix réel et produit non trouvé ;
- clôture explicite et mise à jour du stock ;
- historique complet des décisions ;
- sauvegarde et restauration JSON ;
- installation PWA et fonctionnement hors ligne ;
- mise à jour contrôlée par l’utilisateur ;
- mode développeur masqué, activable par sept appuis sur le numéro de version.
