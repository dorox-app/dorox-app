# DOROX V1

Application locale de gestion des courses, des stocks et du budget familial.

## Utilisation

1. Ouvrir `index.html` dans un navigateur récent.
2. Mettre à jour l’inventaire.
3. Générer la liste proposée dans **Préparer**.
4. Valider, modifier, reporter ou écarter les produits.
5. Utiliser le **Mode Courses**, renseigner les prix réels et clôturer l’inventaire.
6. Exporter régulièrement une sauvegarde JSON depuis le tableau de bord.

Aucun compte ni service payant n’est requis. Les données sont enregistrées localement dans le navigateur.
